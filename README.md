# aiarchlab-workbench

AIArchLab 的共用工作區：給 CMO 與 CTO 以公開連結讀取的工作文件。

**狀態：內部工作文件，去識別，非對外成品。**

## 用途

- 讓 CMO、CTO 不需要雲端硬碟或私有 repo，就能讀到同一份、已去識別的工作文件。
- 只放可公開的去識別內容。哪些東西絕對不放，見 [CONTENT_POLICY.md](CONTENT_POLICY.md)。

## 目錄

- `tasks/`：給各角色的任務單
- `analyses/`：分析與評分
- `reference/`：參考資料

| 檔案 | 內容 | 版本 | 狀態 |
|---|---|---|---|
| [analyses/candidate-scoring.md](analyses/candidate-scoring.md) | 候選案評分表（去識別，案A～案Q） | v1 | 目前有效 |
| [tasks/pilot-review-task.md](tasks/pilot-review-task.md) | 試點評估任務單（CMO、CTO 各自作答） | v1 | 目前有效 |
| [CONTENT_POLICY.md](CONTENT_POLICY.md) | 內容政策：不可放入的內容 | v1 | 目前有效 |
